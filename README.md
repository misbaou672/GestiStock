## 🛠️ Stack Technique

- **Langage** : Python 3.10+
- **Interface Utilisateur** : Tkinter, TTK
- **Manipulation de Données** : OpenPyXL, JSON, CSV
- **Architecture** : Modulaire (Gestionnaire de stock, Contrôleurs UI, Rapports)

---

## 🚀 Prise en main rapide

```bash
# 1. Cloner le dépôt
git clone https://github.com/misbaou672/GestiStock.git
cd GestiStock

# 2. Installer OpenPyXL
pip install openpyxl

# 3. Lancer l'application
python gestion_stocks.py
```
